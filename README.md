# ML_web

Интерактивный курс машинного обучения: 26 уроков, вопросы и задачи,
лаборатория, scikit-learn и PyTorch. Адаптивный интерфейс, прогресс в браузере.

## Запуск

Выполни `python3 start.py` и открой локальный адрес. Для запуска Python в браузере нужен HTTP-сервер, открытие файла напрямую не подходит.
На macOS можно запустить `Запустить сайт.command`.

## Python-практика

Python 3.10+:

```sh
python3 -m venv .venv
source .venv/bin/activate
pip install -r practice/requirements.txt
python practice/01_sklearn_iris.py
python practice/02_pytorch_iris.py
```

На Windows: `.venv\Scripts\activate` вместо `source`.
Практикумы работают на CPU; результаты сохраняются в `practice/outputs/`.

## Задачи с кодом

26 упражнений в разделе «Задачи с кодом»: 14 функций на Python с проверкой на нескольких входах и 12 упражнений на вызовы sklearn/PyTorch. Во втором режиме проверяется Python AST, библиотеки не запускаются. Черновики и прогресс хранятся локально в браузере.

Python работает через Pyodide 0.27.7 в отдельном Web Worker. Первый запуск требует доступа к cdn.jsdelivr.net. Есть остановка, лимит выполнения 5 секунд и ограничение вывода. Сервер не выполняет пользовательский код.

Проверки: `node check-coding.cjs` (нужен также `python3`).

## Метрики и собеседования

Раздел `#metrics`: 8 уроков, 8 новых задач Python и 16 вопросов для устной тренировки с сохранением тезисов и самооценки. Темы: confusion matrix, precision/recall/Fβ, цена ошибок и порог, ROC-AUC/AP, log loss/Brier/калибровка, способы усреднения, регрессия и честное сравнение моделей.

`#metriclab` — интерактивный порог, матрица ошибок, затраты, ROC и PR на фиксированной учебной validation. `#interview` — тренировка ответов. Старые индексы уроков и сохранённый прогресс остаются действительными; теперь 26 уроков и 4 модуля.

`node check-metrics.cjs` сравнивает расчёты с sklearn в `.venv/bin/python`. Подготовь окружение командой установки из раздела Python-практики. Тест покрывает крайние пороги, совпадающие scores и обратное ранжирование.
